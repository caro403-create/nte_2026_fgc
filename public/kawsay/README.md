# Imágenes de la sección «El nombre: Kawsay»

La sección de Saberes (`src/components/AncestralKnowledge.jsx`) espera estos dos
archivos aquí. Los nombres importan: el código los referencia literalmente.

| Archivo | Qué es | Formato sugerido |
|---|---|---|
| `logo.png` | El logo de Kawsay | PNG con fondo transparente, cuadrado, mínimo 600×600 px |
| `comunidad.jpg` | Fotografía de la comunidad indígena quechua | JPG apaisado, mínimo 1600 px de ancho |

Mientras no existan, la sección muestra un recuadro punteado con la leyenda
«Espacio reservado para la imagen». En cuanto se suban con el nombre correcto,
aparecen solas: no hay que tocar código.
